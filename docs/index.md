## 🚀 Démarrage rapide

```bash
# 1. Cloner le repository
git clone https://github.com/username/apple-game.git
cd apple-game

# 2. Installer les dépendances
pip install -r requirements.txt

# 3. Lancer la documentation
mkdocs serve

# 4. Ouvrir Godot et charger le projet
# project.godot
```
