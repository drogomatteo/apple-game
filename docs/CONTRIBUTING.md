# 🤝 Contribution

Merci de votre intérêt pour AppleGame ! Cette page présente les bonnes pratiques pour contribuer au projet.

## Comment contribuer

1. Créez une issue pour décrire le problème ou la fonctionnalité.
2. Travaillez sur une branche dédiée.
3. Faites une pull request avec une description claire.
4. Ajoutez des captures d'écran ou des étapes de reproduction si nécessaire.

## Règles de base

- Respectez le style de code existant.
- Documentez les modifications importantes.
- Testez vos changements dans Godot.
- Si vous modifiez des ressources, vérifiez les licences.

## Documentation

- Mettez à jour cette documentation si vous ajoutez une nouvelle fonctionnalité.
- Les sections principales sont `Architecture`, `Gameplay` et `Développement`.

## Revue de code

- Les PR doivent être revues par au moins un membre de l'équipe.
- Rebasez votre branche si nécessaire avant la fusion.
- Assurez-vous que la documentation reste cohérente avec le code.
